# Document Reader Capacitor — example

Ionic React demo for `document-reader-capacitor`.

```bash
# from repo root
npm install && npm run build
cd example
npm install
# place documentreadersdk.aar → android/libdocsdk/
# place docsdk.framework → ../ios/Frameworks/
npm run sync
npx cap open android   # or ios
```

See the [root README](../README.md) for licenses, app ids, and troubleshooting.
