# Android runtime (customer install)

Place **`documentreadersdk.aar`** here after installing `document-reader-capacitor`:

```text
node_modules/document-reader-capacitor/android/libs/documentreadersdk.aar
```

Download from the [FacePlugin Android Drive folder](https://drive.google.com/drive/folders/1nDSfvj0WtC1lZgzwFd7471ECVtk-nuYH) (same file as `DocumentReader-Android-App/libdocsdk/`).

Do not commit the AAR.
